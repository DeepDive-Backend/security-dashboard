## 보안 위협 탐지 현황 대시보드
대량 보안 이벤트의 실시간 집계 쿼리가 DB에 과부하를 주어 모니터링 대시보드가 지연되는 문제를 해결합니다.

## 문제 상황
보안 시스템에는 지속적으로 대량의 이벤트가 발생합니다.  
모니터링 대시보드는 이벤트 데이터를 기반으로 실시간 통계 및 탐지 현황을 제공해야 합니다.  
하지만 데이터가 증가하면서 집계 쿼리의 비용이 증가하고, DB 부하와 함께 **대시보드 응답 시간이 증가하는 문제가 발생**합니다.

## 목표
- 대량의 보안 이벤트 데이터 생성
- 실시간 집계 API 구현
- 데이터 증가에 따른 성능 저하 재현
- DB 및 애플리케이션 병목 분석
- 개선 방법 설계 및 적용
- 개선 전/후 성능 비교

## 계획
- 보안 이벤트 테이블 설계 및 수십만 건 시드 데이터 생성 스크립트 작성
- 집계 쿼리 구현
- 집계 결과 반환 REST API 구현 및 기본 응답시간 측정
- DB 인덱스 적용 전 EXPLAIN 분석 및 기록
- 복합 인덱스(event_type, occurred_at) 적용 후 EXPLAIN 재분석 및 비교
- Redis 캐시 레이어 구현 - @Cacheable, TTL 설정, 캐시 키 전략
- 캐시 히트/미스 매트릭 Prometheus 연동 및 Grafana 패널 구성
- k6 또는 nGrinder 부하 테스트 스크립트 작성 및 캐시 적용 전 측정
- 캐시 적용 후 동일 조건 부하 테스트 재측정 및 결과 비교
- 결과 문서화, 캐시 무효화 전략 검토, 자료 준비
